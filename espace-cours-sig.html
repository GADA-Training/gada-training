Bienvenue dans votre espace de formation !

Cet espace sécurisé regroupe toutes les ressources exclusives, supports de cours et bases de données nécessaires pour votre parcours en Modélisation Spatiale et Statistique (Approche One Health).

1. Logiciels & Outils

Téléchargez et installez l'environnement technique complet requis pour les sessions pratiques :

  • ArcGIS Pro / ArcMap : Fichiers d'installation et extensions.
  • R & RStudio : Packages d'analyse de données et modélisation.
Accéder aux téléchargements

2. Modules & Données

Retrouvez les guides méthodologiques (Syllabus) ainsi que les couches de données géospatiales (Shapefiles, rasters) répartis selon notre programme :

  • Module I : R : Fondements & Exploration de données (Semaine 1)
  • Module II : R : Intégration One Health & Modélisation avancée (Semaine 2)
  • Module III : ArcGIS : Fondements & Production Cartographique (Semaine 3)
  • Module IV : ArcGIS : Analyse Avancée & Projet Intégré (Semaine 4)
